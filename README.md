# Improved Zetamac

A browser drill based on the layout and controls of [Arithmetic Zetamac](https://arithmetic.zetamac.com/), with powers, roots, and dark mode.

[Play on GitHub Pages](https://simonvu617.github.io/Improved-Zetamac/) or open `index.html` in a browser. Choose your drills, set the ranges and duration, and click **Start**. The default round lasts 120 seconds.

**Powers** and **Roots** share a base range and a fixed exponent. Use exponent 2 for squares and square roots, or 3 for cubes and cube roots.

Correct answers advance as you type.

Use **Dark mode** to switch themes. At the end of a round, **Try again** uses the same settings.
