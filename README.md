# Improved Zetamac

A browser drill based on the layout and controls of [Arithmetic Zetamac](https://arithmetic.zetamac.com/), with squares, prime factorization, and dark mode.

Open `index.html` in a browser. Choose any combination of the six drills, set the ranges and duration, and click **Start**. The default round lasts 120 seconds.

Correct number answers advance as you type. For prime factors, type the full list with spaces or commas and press **Enter**. Include repeats in any order.

Use **Dark mode** to switch themes. At the end of a round, **Try again** uses the same settings.
